## 確認範囲

配布する開始文は、2026年11月19日公開のnote掲載文と同一です。この版での新規作成・保存・読戻し・別チャット再開の一連の動作は未検証です。iPhone、無料プラン、初回接続、別のAIへの引継ぎも未確認です。配布ページの表示やコピーの確認と、ネタ帳自体の実機検証は別です。

感想や困ったことは、個人情報を含めずnoteの記事コメントへ。個別のサポートは行っていません。

## ページの管理

ビルドや外部ライブラリを使わないHTML・CSS・JavaScriptで構成しています。GitHub Pagesの公開元を `main` ブランチのルート `/` に指定して配信します。

開始文を改訂するときは、新しい版のテキストファイルを追加し、ページ内の全文・版表示・ダウンロード先・文字数・更新履歴を揃えて更新します。過去版は同じURLで保持します。公開済みnoteとの対応も確認します。

ここには公開用の開始文と配布ページだけを置きます。利用者の記録、作品、保存先の個別リンクや非公開ログを置く場所ではありません。
