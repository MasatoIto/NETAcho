## 確認範囲

公開中のnote記事は現行v03へ更新済みです。v02は初回公開時の版として保持しています。現行のv03は初回相談後にAIからクラウド接続確認を提案し、未決定・未採用もその状態のまま記録できることを明確にした改訂版です。v03での新規作成・保存・読戻し・別チャット再開の一連の動作は未検証です。iPhone、無料プラン、初回接続、別のAIへの引継ぎも未確認です。配布ページの表示やコピーの確認と、ネタ帳自体の実機検証は別です。

感想や困ったことは、個人情報を含めずnoteの記事コメントへ。個別のサポートは行っていません。

## ページの管理

ビルドや外部ライブラリを使わないHTML・CSS・JavaScriptで構成しています。GitHub Pagesの公開元を `main` ブランチのルート `/` に指定して配信します。

開始文を改訂するときは、新しい版のテキストファイルを追加し、ページ内の全文・版表示・ダウンロード先・文字数・更新履歴を揃えて更新します。過去版は同じURLで保持します。公開済みnoteとの対応も確認します。

## 公開物の版管理

開始文・配布ページ・note公開原稿の版管理は、このリポジトリで行います。noteを改訂するときは `articles/note-01.md` と変更履歴を更新し、旧稿はGitのコミット履歴で追えるようにします。note記事には最新版の開始文だけを掲載し、過去版から選ばせません。ARYSKには採用判断と公開・検証結果、このリポジトリへの参照を記録します。

ここには公開用の開始文・配布ページ・note公開原稿を置きます。利用者の記録、作品、保存先の個別リンクや非公開ログを置く場所ではありません。
